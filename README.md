# 🤖 Call Hunter v2

Call Hunter v2 is an advanced Telegram bot for **crypto & forex market analysis**.
It combines live market data, technical indicators, AI reasoning, and visual chart analysis.

⚠️ Educational only — **NOT a signal bot**.

---

## 🚀 Features

- 📊 Live crypto & forex prices
- 📈 EMA, RSI, MACD, Volume analysis
- 🧠 AI market reasoning (context-aware)
- 🧱 Supply & Demand zones
- 🕰 Multi-timeframe (HTF / LTF) bias
- 👁 Chart screenshot (vision) analysis
- 🔐 Numeric confidence scoring
- 🛡 Crash-proof & production-safe design

---

## 📌 Commands

### `/price PAIR`

### 📸 Chart Analysis
